# Watcher project audit, 2026-10-23

Read-only audit of the whole repository. No files were changed during the audit. Issue IDs match `ISSUES.md`, which tracks their current status. The batch 1 fixes that followed are summarized at the end.

## Scope

**Inspected:**
- every tracked file: `index.html` (2,896 lines, 751 KB, of which about 545 KB is the app script with embedded data and 94 KB is CSS), `data/geo.json` (2.0 MB), `data/detail.json` (4.8 MB) and `brand/`;
- git history (207 commits);
- the external services the site loads, and its runtime behavior in a test browser.

**No README, LICENSE, tests or CI** existed at the time.

**Not inspected:** live map tiles (blocked in the test browser), Safari, Firefox, and real phones.

## Overall health (at audit time)

| Area | Score | Evidence |
|---|---|---|
| Reliability | 7/10 | No JavaScript errors at 1440, 820 and 390px. All views, search (12/12), the claims ledger (52/52) and the quiz work. No horizontal scrolling. No broken links between entries. |
| Code quality | 5/10 | A consistent style, but one very large file mixing code, styles and data. Three unused functions and a leftover publishing path. |
| Security | 8/10 | Static site with no secrets. Visitor text is escaped (verified with an injection test). The CDN script had no integrity check. |
| Maintainability | 4/10 | No docs, no automated checks. Data edits relied on hand-run scripts. |
| Production readiness | 6/10 | Fine as a public hobby site. Monetization is blocked on asset and imagery licensing (L-1, L-2). Weak discoverability (SEO-1, SEO-2). |

No critical defects were confirmed. The high-priority items were L-1, L-2, M-1 and SEO-2.

## Findings

All of these are tracked in `ISSUES.md`:

- **Legal and licensing:**
  - L-1: agency seals and program emblems with no recorded provenance, and restrictions on using some seals.
  - L-2: Esri imagery's commercial terms.
  - L-3: no license, and a missing ISC notice for the bundled code.
  - PR-1: third-party fonts and tiles see visitors' IP addresses.
- **Maintainability:** M-1 (no automated checks), D-1 (no documentation), D-2 (map data provenance), C-1 (leftover publishing code), C-2 (unused functions).
- **Data:**
  - W-1: 12 Wikipedia sources returned 404.
  - W-2: a stale citation phrase, one duplicate source URL, and two unused sources.
  - T-1: about 60% of non-claim entries have no statement-level citations, and 72% of sources are Wikipedia.
- **Security:** S-1 (no integrity check on MapLibre).
- **Discoverability and UX:** SEO-1 (no description or preview tags), SEO-2 (no per-entry links), UX-1 (no About or methodology panel).
- **Performance and accessibility:** P-1 (`geo.json` fetched on every visit), C-3 and C-4 (accessibility checks).
